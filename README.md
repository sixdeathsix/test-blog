# Блог на PHP + Smarty + MySQL

Блог с категориями и статьями на чистом PHP 8.1+ без фреймворков: шаблоны на Smarty 5, база MySQL 8.4, стили на SCSS, окружение в Docker.

## Требования для запуска

- Docker Desktop (или Docker Engine) с Docker Compose v2

PHP, MySQL и Composer на компьютере не нужны: всё работает в контейнерах.

## Запуск

Скопируйте `.env.example` в `.env`:

**Windows (CMD):**
```cmd
copy .env.example .env
```

**Linux/macOS:**
```bash
cp .env.example .env
```

Затем выполните команды:

```bash
docker compose up -d --build
docker compose exec php composer install
docker compose exec php composer migrate
docker compose exec php composer seed
```

Сайт откроется по адресу http://localhost:8080

*Первый запуск занимает несколько минут: скачиваются образы и собирается PHP.*

## Команды

| Команда | Что делает |
|---|---|
| `docker compose exec php composer migrate` | Создаёт таблицы. Повторный запуск безопасен |
| `docker compose exec php composer seed` | Очищает таблицы и заполняет их тестовыми данными |
| `docker compose run --rm sass` | Компилирует SCSS в CSS |
| `docker compose down -v` | Останавливает контейнеры и удаляет тома, включая данные БД |

## Подключение к базе

GUI-клиент (HeidiSQL и т. п.): хост `127.0.0.1`, порт `3307`, пользователь, пароль и база задаются в `.env`.

## Страницы

- `/` — главная: категории со статьями, в каждой три последние статьи и кнопка «Все статьи»
- `/category/{slug}` — категория: название, описание, список статей, сортировка по дате и просмотрам, пагинация
- `/article/{slug}` — статья: полная информация и три похожие статьи

## Структура

```
bin/            консольные команды: migrate, seed
config/         настройки приложения, блога и маршруты
database/       SQL-миграции и сидеры
docker/         конфиги nginx и PHP
public/         точка входа index.php и статика
resources/scss/ исходники стилей
src/            код: Core, Controller, Service, Repository, Entity, Dto, Support
templates/      шаблоны Smarty
```

Запрос проходит путь `index.php → Router → Controller → Service → Repository → MySQL`, а HTML собирается в шаблонах Smarty с автоэкранированием.

## Осознанные упрощения

- Просмотр засчитывается при каждом открытии статьи, обновление страницы тоже увеличивает счётчик.
- Миграции — идемпотентные `CREATE TABLE IF NOT EXISTS` без таблицы учёта: схема в задании стабильная.
- Скомпилированный CSS лежит в репозитории, чтобы для запуска не требовался Node.js.
- Плейсхолдеры вместо реальных изображений. Это позволяет сохранить целостность визуального оформления без хранения медиафайлов.
